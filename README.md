# Schengen Insurance

Учебный сайт страхования на CodeIgniter 4. На сайте можно рассчитать стоимость по учебным тарифам и сохранить заявку в локальную базу SQLite. В проекте есть демонстрационный шаг оплаты с тестовой картой. Реальные платежи и отправка писем не предусмотрены.

## Локальный запуск на Windows

1. Откройте проект в PhpStorm и запустите терминал в папке, где лежит `spark`.

2. Проверьте PHP:

   ```powershell
   php -v
   php -m
   ```

   В списке расширений должны быть `intl`, `mbstring` и `sqlite3`. Если PowerShell не находит `php`, используйте полный путь к `php.exe`, например: `& "C:\php\php.exe" spark serve`.

3. Если файла `.env` ещё нет, создайте его из шаблона:

   ```powershell
   Copy-Item env .env
   ```

   В `.env` укажите локальный адрес:

   ```ini
   app.baseURL = 'http://localhost:8080/'
   ```

4. Создайте таблицы и запустите сервер:

   ```powershell
   php spark migrate
   php spark serve
   ```

   `migrate` применяет миграции — файлы, в которых описана структура таблиц. SQLite хранит базу в файле `writable/schengen.sqlite`. Отдельный сервер базы данных не нужен.

5. Откройте [сайт](http://localhost:8080/). Чтобы остановить сервер, нажмите `Ctrl+C` в терминале, где он запущен.

## Как проверить сохранение заявки

Заполните форму расчёта, перейдите к результату и нажмите **Save and continue**. После сохранения откроется демонстрационный шаг с номером заявки. Используйте тестовые данные из подсказки на экране.

В другом терминале можно проверить структуру таблиц:

```powershell
php spark migrate:status
php spark db:table insurance_applications
php spark db:table application_tourists
```

- `insurance_applications` — заявки, их статус и рассчитанная стоимость.
- `application_tourists` — туристы, привязанные к заявкам через `application_id`.

В Git хранятся код и миграции. Локальный `.env`, файл базы с заявками и логи в репозиторий добавлять не нужно.
